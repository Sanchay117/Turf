        Field notes

        Rules of the survey

        1. Claim any hex that touches your land. Open land costs one point of energy. Click a hex further out and the page runs the cheapest chain of claims to it, up to 12 hexes in one transaction.
        2. Energy refills one point per Solana slot, up to 30. This page measures a slot at 240 ms right now.
        3. Enemy land costs 2, plus 1 for every neighbouring hex its owner holds. Solid land holds; thin lines break.
        4. A round lasts 600 slots, about 2.4 minutes at that pace. The most land wins and is written into the Champions register on-chain.
        5. Wiped out? Click any open hex to parachute back in.

        What runs on-chain

        The whole game is one Anchor program and one account per plat: the board, every seat, every energy meter and the champions register. There is no game server. The page only reads the account and sends signed claims; the program checks every rule.

        Send your own surveyor

        The program is open. Anyone can write a bot against it; this one takes the cheapest open hex next to its land.

        import { claimIx } from "./chain/ix.ts";
import { claimCost, liveEnergy } from "./chain/layout.ts";

const me = arena.players[seat];
const options = [...arena.tiles.keys()]
  .map((i) => [i, claimCost(arena.tiles, i, seat, me.tiles)])
  .filter(([, cost]) => cost !== null && cost <= liveEnergy(me, slot))
  .sort((a, b) => a[1] - b[1]);

await chain.send("claim", [claimIx(arenaAddress, key.publicKey,
  options.slice(0, 12).map(([i]) => i))], [key]);

        The chain

        In 1620 Edmund Gunter made a surveyor's chain 66 feet long, of 100 links. Ten square chains make an acre, and a cricket pitch is still exactly one chain. Each hex on this plat is one chain across.

        Type: IM Fell English, from the Fell Types digitised by Igino Marini; Spectral by Production Type; IBM Plex Mono. Rival surveyors are named for Charles Mason, Jeremiah Dixon, George Everest, Benjamin Banneker and William Lambton.
